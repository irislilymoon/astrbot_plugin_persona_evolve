# 人格自迭代

按周期用「近期对话 + 长期记忆」重写**当前正在使用**的那一份人格。
其他人格原样不动；写入前自动备份，可回滚，字数有上限。

## 它改的是哪一份人格

按 AstrBot 自己的解析顺序找会话实际生效的人格：

1. 会话被强制指定的人格（`preferences` 里 `session_service_config.persona_id`）
2. 会话当前选中的人格（`conversations.persona_id`）
3. 全局默认人格

**不能只看 `conversations.persona_id`**：在 WebUI 里给某个会话单独指定人格时，
这个字段仍是 `None`，真正的人格写在 `preferences` 里。私聊被指定成「私聊」人格就是这种情况。

## 上下文与记忆的边界

一份人格只吃自己的上下文，不串台：

- **对话**：按会话解析出生效人格，只有人格等于目标的会话才进素材。
  群里用默认人格、私聊用私聊人格，两边历史不会混在一起。
- **记忆**：LivingMemory 按对话分割记忆，`memory_atoms.session_id` 就是 umo。
  所以先按「属于这份人格的 umo 列表」过滤，再退回按 `persona_id` 过滤，
  最后才不加限制（该人格还没有任何记忆时）。
- 一份人格对应多个会话（比如多个群共用一份人格）时，这些会话会一起算作它的上下文。

定时迭代按人格分别计时：每份在用的人格各自满一个间隔就迭代一次，
互不影响。`iterate_all_active=false` 时退化成每轮只迭代最近活跃的那一份。

## 指令（仅管理员）

| 指令 | 说明 |
| --- | --- |
| `/人格迭代` | 查看目标人格、间隔、下次时间、上次结果 |
| `/人格迭代 立即` | 马上迭代并写入 |
| `/人格迭代 预览` | 只生成不写入，直接回一段预览 |
| `/人格迭代 历史` | 列出历史版本（1 为最新） |
| `/人格迭代 回滚 1` | 回到上一次迭代之前 |

## 面板

插件带一个页面 `pages/panel`，在 AstrBot 面板的插件卡片里点开就能用：

- 顶部「演练一次」：只生成不写入，结果直接弹窗看，同时存到插件数据目录
- 顶部「立即迭代」：当场生成并写入，写完自动打开新版本的红绿对比
- 左侧列出所有人格，标出哪几份正在使用、各有多少会话、多少版本
- 中间是历史版本列表，点开看「迭代前 / 迭代后」两段正文，可直接编辑保存；「对比」按行 + 按词双级高亮，带新旧行号
- 编辑内容不保存也能直接切走，草稿按人格/版本分别留着，切回来还在；「放弃修改」丢弃草稿
- 「应用到当前人格」把选中的文本写回去，写入前照例先备份，可再回滚
- 「删除版本」连文件一起删，不可恢复
- 顶部「当前生效的人格正文」可以展开看现在用的是哪一版

对应的接口都在 `/{plugin}/page/*` 下，注册在插件加载时，随插件启停生效。

## 配置要点

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `enabled` | true | 自动迭代总开关 |
| `interval_days` | 1.0 | 迭代频率，支持小数 |
| `iterate_all_active` | true | 多份在用的人格各自迭代；关掉只迭代最近活跃的一份 |
| `max_personas_per_run` | 3 | 每轮最多迭代几份 |
| `max_chars` | 800 | 改写后字数上限，超出按句子边界裁剪 |
| `min_chars` | 200 | 低于此长度视为失败，保留原人格 |
| `keep_lines` | 禁止发布任何网络链接。 | 强制保留的硬性规则行 |
| `recent_days` | 7 | 只读这段时间内的素材 |
| `use_livingmemory` | true | 只读 LivingMemory 的 livingmemory.db |
| `dry_run` | false | 只生成不写入 |
| `run_on_start` | false | 首次加载不立即跑，先记录起点 |
| `notify` | false | 迭代后在私聊/webchat 发一条通知，不发群 |

## 取材来源

- **对话**：AstrBot 自己的 `conversations` 表，只取实际使用同一人格、时间范围内的最近 3 个会话。
- **记忆**：`plugin_data/astrbot_plugin_livingmemory/livingmemory.db` 的 `memory_atoms`，
  只读、按人格与时间过滤，取重要度最高的若干条。

任一来源缺失只是少一段材料，不影响运行；两类都没有时本轮跳过，不改人格。

## 数据文件

```
plugin_data/astrbot_plugin_persona_evolve/
├── state.json                     # 上次运行时间、最后会话、失败计数
├── debug.log                      # 开 debug 才有
├── preview-*.txt                  # 演练模式产物
└── versions/<人格ID>/
    ├── index.json                 # 版本索引
    ├── <时间戳>.old.txt           # 迭代前的文本（回滚源）
    └── <时间戳>.new.txt           # 迭代后的文本
```

## 注意

- 自动迭代不消耗消息：一天一次模型调用，每份在用的人格各一次。
- 没有新素材时会跳过本轮并把计时推后一个周期，避免无意义改写。
- 失败（超时、输出过短、写回校验不一致）不会动原人格，日志里能看到原因；失败会每小时重试，最多 3 次。
- 模型可能不听话，第一次建议先 `/人格迭代 预览` 看效果，再决定是否 `/人格迭代 立即`。
- 一个会话中途换过人格时，切换前后的历史分不开，只能整段按当前人格算；这种情况建议换人格时开新对话。
